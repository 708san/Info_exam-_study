# 応用情報技術者試験｜学習アプリ（2027年3月対策）
講義、科目Aの四肢択一演習、公式過去問の採点支援、科目Bの記述練習、進捗・復習管理をブラウザで利用できる自主学習用アプリです。**IPA（情報処理推進機構）非公式の教材**です。

## GitHub Pagesで公開
リポジトリをPublicに変更後、**Settings → Pages → Build and deployment → Source: Deploy from a branch → main → /(root) → Save** に設定。
想定URL： https://708san.github.io/Info_exam-_study/
公開設定と実際の公開成功は、Actions・Pages画面とURLを確認するまで確定していません。

## iPhoneで使う
公開URLをSafariで開く → Safariの共有 → 「ホーム画面に追加」。
学習管理で目標問題数、直近7日、23分野の理解度、復習予定、過去問得点などを確認できます。
教科書： [PDF（約64ページ）](./textbook.pdf)

## 保存と注意
- 進捗や記述答案は端末のブラウザ内のlocalStorageに保存され、クラウド同期・ログインはありません。
- Safariとホーム画面追加版で保存領域が異なる場合があるため、普段は同じ起動方法を使うことを推奨。
- 定期的に「学習管理 → バックアップ」からJSONデータをiCloudなどに保存してください。
- データを失わないよう、閲覧データ削除・プライベートモードには注意。
- 学習記録のJSONや個人情報をこの公開リポジトリにコミットしないでください。
- 科目Bは自己評価の支援であり、自動採点ではありません。公式過去問で必ず演習を追加してください。
- 合格保証ではなく、学習開始用の教材です。制度・日程は [IPA](https://www.ipa.go.jp/shiken/) の最新情報を確認してください。
