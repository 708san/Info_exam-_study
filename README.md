# AP Study Lab 2027｜応用情報技術者試験 詳解学習アプリ

## 学習教材（2026年11月26日改訂）

- 教科書：全23章、126単元。仕組み・途中式・事例・確認問題と解答を収録。全126単元に図表と解説。第1〜11章の70単元を原理から段階的に説明する教科書本文へ増補。全126単元に初学者向け具体例・誤答注意・単元別問題を追加。初学者ガイド、各章に学習の導入、単元別演習の挑戦状況と講義への戻り導線、重点23問の段階解説を追加。章の到達度は異なる問題への挑戦率と通算正答率を区別。公式小分類96項目への教材対応索引（全細目の検証は未完了）。
- 科目A：オリジナル四肢択一538問（用語234問／応用304問）。誤答記録と復習予定、80問模試。
- IPA公式：2024年度・2025年度の科目A過去問320問の解答入力・自動採点補助。問題冊子はIPA公式サイトで開く。
- 科目B：独自ケース22件、記述設問92問。全11分野に基礎・応用ケースを収録。記述は自己採点。
- 印刷向けの詳解教科書 [textbook.pdf](./textbook.pdf)（54ページ、旧版）も同梱。
- 学習管理：単元読了、章の修了、目標問題数、誤答、時間・得点、バックアップを端末内に保存。

## iPhoneでの使用

Safariで公開URLを開き、「共有 → ホーム画面に追加」。学習開始後は同じ起動方法で利用することを推奨。

## 学習記録・個人情報

学習データはそのブラウザ/ホーム画面アプリ内の `localStorage` に保存し、クラウド同期は行いません。閲覧データ削除や端末交換で失うことがあるため、学習管理からJSONバックアップを定期的に書き出してください。**個人の学習記録を公開リポジトリへ追加しないでください。**

旧版の記録キー `ap-study-2027-v1` を引き継ぎます。既存の読了・解答履歴は保持。追加単元を未読として扱い、章修了は全単元読了時のみ表示します。

本教材はIPA非公式のオリジナル教材です。シラバスの全細目を完全に再現したり合格を保証したりするものではありません。科目Bは公式過去問の問題文・解答例・採点講評で実戦形式の学習を行ってください。公式： https://www.ipa.go.jp/shiken/
